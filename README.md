# Hand Cricket Arena 🏏

Hey there! Welcome to **Hand Cricket Arena**. 

If you grew up in India, chances are your school days were filled with frantic hand-sign battles under the desk, trying to score runs or take that crucial wicket before the teacher turned around. This project brings those nostalgic school corridor memories back to life—right inside your web browser, but with a modern upgrade!

Whether you want to play a quick offline match on your lunch break or challenge a friend to a high-stakes match online, we've got you covered.

---

## 🎮 What makes this special?

- **Real-Time Multiplayer with Friends**: No messy login forms, passwords, or databases. Just type in a shared 4-digit code generated on your screen, and you're instantly connected to play head-to-head with your friend!
- **Play Offline with Smart AI**: Alone? Don't worry! You can play against our AI bots. They aren't just choosing random numbers—they have distinct personalities:
  - *Captain Sharp* (Tactical and calculates your patterns)
  - *Power Smasher* (Aggressive, goes for big runs)
  - *Mystery Spinner* (Tricky, loves to change pace)
  - *Steady Anchor* (Defensive, plays safe shots)
- **Voice of the Game**: Experience the excitement of live cricket! We've written commentary lines inspired by the legendary, high-energy voice of **Ian Bishop** (yes, including *"Remember the name!"* when you hit a maximum!).
- **True Toss Realism**: The coin flip is a genuine, suspenseful 50/50 chance. Call it in the air, see it flip, and make your tactical choice to bat or bowl first.
- **Easy on the Eyes (No Eye-Strain)**: We ditched the harsh neon colors and dark-mode glare. The game features a soft, warm light theme (resembling classic paper and turf) with high-contrast borders so you can easily tell the boards, buttons, and scores apart.
- **Dynamic Score popups**: Score a run, and you'll see a satisfying `+Runs` indicator pop up directly over the active batter's side.

## 🛠️ How to get it up and running on your computer

Follow these steps to get a local copy of the project up and running.

### 1. Prerequisites

Make sure you have [Node.js](https://nodejs.org) installed (version 18.x or higher recommended). Check your version by running:

```bash
node -v
```

### 2. Clone the Repository

```bash
git clone https://github.com
cd your-repo-name
```

### 3. Install Dependencies

Install all the required packages listed in the `package.json` file:

```bash
npm install
```

### 4. Run the Development Server

Start the project in local development mode with live-reloading:

```bash
npm run dev
```

Once started, open [http://localhost:3000](http://localhost:3000) (or the port specified in your terminal) in your browser to view the application.
